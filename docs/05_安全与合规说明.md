# 安全与合规说明

## 1. 身份安全

用户认证使用服务端签发的令牌，密码不得明文存储。生产环境必须使用随机高强度密钥、HTTPS、令牌过期和撤销策略，并限制登录失败频率。

## 2. 权限安全

权限采用最小授权原则，接口服务端执行角色和数据范围校验。前端菜单隐藏只改善体验，不能替代后端鉴权。普通用户只能访问本人数据，运营人员只能访问授权社区。

## 3. 数据安全

敏感字段传输加密、存储加密或脱敏；日志和 Agent 记忆禁止写入密码、令牌、支付密钥和完整身份号码。数据库账号按服务拆分，生产数据库禁止公网暴露。

## 4. Agent 安全

模型只能调用登记工具；工具参数必须校验；模型不得执行任意 SQL、系统命令或绕过审批。高风险操作展示影响范围、金额和目标设备，由授权人员审批后执行，执行结果必须回执和审计。

## 5. 审计与留痕

登录、权限拒绝、设备事件、订单状态、工单、审批、Agent 工具调用和数据导出均写入审计日志。审计日志设置保留周期、访问控制和防篡改存储策略。

## 6. 生产基线

上线前完成依赖漏洞扫描、密钥扫描、接口越权测试、备份恢复演练和应急预案演练。生产环境关闭调试模式，限制 API 文档和管理端访问，建立安全事件响应联系人和升级路径。
